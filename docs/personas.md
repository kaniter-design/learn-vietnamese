### Motivations
- **Professional Growth** — Enhancing public sector/business relations with Vietnam, coordinating with international counterparts.
- **Language Passion** — Enjoys learning languages as a hobby (already learning Chinese, now wants to add Vietnamese).
- **Efficiency** — Wants maximum progress per minute spent, leveraging their good memory to acquire vocabulary rapidly.
- **Practicality** — Wants phrases they can use immediately in real communication.

### Frustrations
- **No Thai→Vietnamese resources** — Everything is English→Vietnamese (though English is fine, learning direct is better).
- **Tones are confusing** — 6 tones, different from Thai tones.
- **Generic content** — Most apps teach travel/tourist Vietnamese, not business or formal registers.
- **Time pressure** — Busy civil servant, needs bite-sized mobile-responsive web learning sessions.

### Learning Preferences
| Preference | Detail |

| **Content type** | Flashcards, roleplay conversation, phrase templates |
| **Feedback** | Immediate, specific, in Thai, utilizing linguistic analogies |
| **Progress** | Visible, gamified, streak-based |
| **Language** | Thai explanations, Vietnamese examples, English translations as secondary checks |
| **Device** | Smartphone / Mobile Web Browser (responsive) primary, Desktop secondary |

### Vietnamese-Specific Challenges (Predicted)

| Challenge | Why | Web Solution |
|-----------|-----|--------------|
| **6 tones** | Thai has 5 tones, Vietnamese has 6 — they don't map 1:1. Chinese has 4 tones, adding confusion. | Dedicated tone training module comparing pitch contours, linking with known Thai/Chinese tones. |
| **Latin script** | Vietnamese uses Latin alphabet with diacritics — looks familiar but pronunciation differs. | Interactive character-by-character pronunciation guides with audio fallback. |
| **Classifier words** | Vietnamese uses classifiers (cái, chiếc, con...) like Thai. | Grammar lessons mapping classifiers directly to Thai equivalents. |
| **Pronouns** | Vietnamese pronouns are complex (age/gender/relationship-based). | Business-appropriate pronoun reference sheet and interactive context-aware roleplays. |
| **Formal vs informal** | Public relations/Business Vietnamese requires formal register. | Register lessons emphasizing formal phrasing (e.g., using "ạ", proper honorifics) from Level 2. |

## 📊 User Journey — High Level

```
Awareness → Onboarding → Level 0 → Level 1 → Level 2 → Level 3-4 → Mastery
   │            │           │          │          │           │          │
   │            │           │          │          │           │          │
   │         Assess      Tones     Survival   Business   Advanced   Real-world
   │         level       + script  convos     basics     business   usage
   │
   └── Discovers bot via recommendation / search
```

### Journey Phases

| Phase | User State | Bot Response |
|-------|-----------|--------------|
| **Awareness** | "I need to learn Vietnamese for work" | Clear value proposition: Thai→Vietnamese, business focus |
| **Onboarding** | First /start | Quick assessment (or skip), set level, explain features |
| **Level 0** | "I know nothing" | Tones, alphabet, pronunciation basics |
| **Level 1** | "I can say hello" | Survival conversations, basic vocabulary |
| **Level 2** | "I can chat simply" | Business basics, email templates, meeting vocab |
| **Level 3-4** | "I can do basic business" | Negotiation, presentations, formal register |
| **Mastery** | "I use Vietnamese at work" | Maintenance mode, advanced phrases, culture tips |
