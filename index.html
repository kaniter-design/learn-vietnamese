Grammar Reference

📌 SVO Structure
Tôi (ฉัน) + yêu (รัก) + bạn (คุณ) = ฉันรักคุณ
📌 Noun + Adjective
คุณศัพท์หลังคำนาม: cái áo đẹp (เสื้อสวย)
❓ Questions
có...không? = ...ไหม? • ở đâu? = ที่ไหน? • bao nhiêu? = เท่าไหร่?
🚫 Negation
không = ไม่ • chưa = ยังไม่
⏱ Tense Markers
đã = แล้ว (อดีต) • đang = กำลัง (ปัจจุบัน) • sẽ = จะ (อนาคต)
📦 Classifiers
cái = ทั่วไป • con = สัตว์ • cây = ต้นไม้ • quả = ผลไม้
